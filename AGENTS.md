# Agent instructions

The standards for working in this repository are in [STANDARDS.md](STANDARDS.md).
This file is the portable pointer to them, because AGENTS.md is the format many
coding agents read; CLAUDE.md points here too. STANDARDS.md is the single source,
so this file stays a pointer rather than a copy that could drift from it.

A project that adopts this baseline has the same kind of pointer, to
STANDARDS.md at the build its pipeline pins. See [USING.md](USING.md) and
D-050 in [DECISIONS.md](DECISIONS.md).
